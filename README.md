# WindowPeek

Find a window and go straight to it.

Keep Omarchy’s fast workflow, and WindowPeek will replace your Dock and Menu Start. Put your open windows in one list on Omarchy’s bar. Search across workspaces and monitors, peek at a window before switching to it, or move it somewhere else. You'll never lose a Hyprland tab again.

[Omarchy Plugins](https://plugins.omarchy.org/plugin.html?id=sarr.windowpeek) · [User guide](https://github.com/Sarr77/WindowPeek/blob/main/docs/GUIDE.md) · [Settings guide](https://github.com/Sarr77/WindowPeek/blob/main/docs/SETTINGS.md) · [Changelog](https://github.com/Sarr77/WindowPeek/blob/main/CHANGELOG.md)

 ![WindowPeek in Wallpaper style, with its hover list and an Instagram preview in Chromium](https://raw.githubusercontent.com/Sarr77/WindowPeek/main/preview.png)

## Installation

```sh
omarchy plugin add https://github.com/Sarr77/WindowPeek --enable
```

Find WindowPeek on Omarchy’s bar, or open it with **Super + Alt + P**.

## What you can do

* Search windows across workspaces, monitors and Hyprland groups.
* Preview a window before switching to it.
* Move windows between workspaces, monitors and the scratchpad.
* Hide previews with **Shift** while sharing your screen.
* Use keyboard shortcuts to supercharge productivity.
* Customize anything. And more…

## Keyboard shortcuts

| Shortcut | Action |
|----|----|
| **Super + Alt + P** | Open WindowPeek |
| Type | Search windows |
| **↑ / ↓** | Select a window |
| **← / →**, then **Enter** | Choose the window or its Move action |
| **Shift + Enter** | Open Move for the selected window |
| **Ctrl + 1–9 / 0** | Switch to a numbered window or group tab |
| **Page Up / Page Down** | Scroll by a page |
| **Esc** | Go back or close |

After opening with **Super + Alt + P**, number keys work without Ctrl for five seconds. **0** selects the tenth window. Change bindings in **Settings → Controls → Keyboard & mouse shortcuts**.

[Full controls](https://github.com/Sarr77/WindowPeek/blob/main/docs/GUIDE.md#keyboard-controls)

## Make it yours

Settings offers 30 languages and live previews while you customize.

| Customize | Options |
|----|----|
| Panel | Wallpaper mode, solid or transparent backgrounds; panel can react to current bar style. Add grain or blur to improve visibility |
| Colors | Set theme colors or choose your own, with saved appearance presets |
| Layout | Change panel or bar size, spacious or compact rows, custom labels |
| Images & Gifs | Choose art to display in Settings and hover panel. Use any of 37 Omarchy animations or place your own files; easy resizing and positioning |
| Behavior | Customize previews, delays, scrolling, shortcuts and hints |

[Explore settings](https://github.com/Sarr77/WindowPeek/blob/main/docs/SETTINGS.md) ·  [Default settings](https://github.com/Sarr77/WindowPeek/blob/main/docs/SETTINGS.md#defaults)

## Updates

**Settings → Controls → Updates** lets you check for updates, review changes and install through Omarchy’s terminal confirmation.

The footer’s **Auto updates** switch enables notifications. The separate **Automatic updates** option installs verified releases automatically. Both start enabled; you control them independently.

[How updates work](https://github.com/Sarr77/WindowPeek/blob/main/docs/UPDATES.md)

## Help

Use **? icon** for hints and **Settings → Controls → Hints and Support** for help.

[Report a bug or post an idea](https://github.com/Sarr77/WindowPeek/issues) · [Troubleshooting](https://github.com/Sarr77/WindowPeek/blob/main/docs/TROUBLESHOOTING.md) · [Known issues](https://github.com/Sarr77/WindowPeek/blob/main/docs/KNOWN_ISSUES.md)

WindowPeek has no telemetry. Window titles and previews are not saved to disk; update checks contact GitHub and the Omarchy catalog.

## Removal

```sh
omarchy plugin remove sarr.windowpeek
```

Your windows and saved preferences stay in place.
